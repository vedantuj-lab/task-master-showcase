# TaskMaster Testing App

A production-ready React Native todo app built to demonstrate **Mobile Application Testing** with **Jest**, **React Native Testing Library**, and **Detox**.

## Overview

- Add, delete, and complete todos
- Persistent local state via AsyncStorage
- Clean Material-inspired UI
- Test IDs on every interactive component
- Unit tests, component tests, and end-to-end tests

## Tech Stack

React Native CLI · React Navigation · AsyncStorage · Jest · React Native Testing Library · Detox · ESLint

## Installation

```bash
npm install
```

### iOS

```bash
cd ios && pod install && cd ..
```

### Android

Ensure the Android SDK, an emulator (e.g. `Pixel_6_API_34`), and `JAVA_HOME` are configured.

## Running

```bash
npm start          # Metro bundler
npm run android    # Android
npm run ios        # iOS
```

## Testing

### Jest (unit + component)

```bash
npm test
npm run test:coverage
```

### Detox (E2E)

```bash
# iOS
npm run detox:build:ios
npm run detox:test:ios

# Android
npm run detox:build:android
npm run detox:test:android
```

## Troubleshooting

- **Metro cache issues:** `npm start -- --reset-cache`
- **Android build fails:** `cd android && ./gradlew clean && cd ..`
- **iOS pods out of date:** `cd ios && pod install --repo-update`
- **Detox emulator not found:** create an AVD named `Pixel_6_API_34` or update `detox.config.js`
- **Reanimated errors:** ensure `react-native-reanimated/plugin` is the **last** entry in `babel.config.js`

## Native projects

The `android/` and `ios/` folders are generated by React Native CLI. Run:

```bash
npx react-native init TaskMaster --version 0.74.1
```

then copy the JS source from this repo over the generated project, or use `npx @react-native-community/cli init` and merge.
